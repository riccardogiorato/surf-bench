Overall = 0.85 × search + 0.15 × access. Search tasks ask for an answer found on the open web; access tasks ask to open a given page or reach a named bot-walled site. Each track scores 0.55 quality + 0.35 pass rate + 0.1 speed. Same group = the 95% paired-bootstrap CI of the gap includes 0, so the order inside a group is not meaningful. Cost = list price × billable calls, published as a column, not scored. "Right, but via mirror" counts live answers that were correct but read from a mirror or aggregator (nitter, redlib, twiscan, airdna…) instead of the site itself; they are scored as fails, because the benchmark asks whether the provider can reach the site.
